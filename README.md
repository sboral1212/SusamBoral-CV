## View and Export

1. Open the HTML file in Chrome or Microsoft Edge.
   No installation or build process is required.

2. To save a PDF, press **Ctrl+P** (or **Cmd+P** on macOS),
   choose **Save as PDF**, and select **A4**.

3. Check the print preview for page breaks and ensure
   no text is clipped before sending the PDF.

## Selected Research and Software Projects

### 1. InDyCORE — Dynamic Submarine Power Cables

**Institution:** Trinity College Dublin, Ireland

**Funding:** Sustainable Energy Authority of Ireland (SEAI)

Research involving mathematical modelling and numerical simulation
of submarine power cables under environmental loading.

The project investigates:

- Nonlinear cable dynamics
- Hydrodynamic loading
- Cable tension and displacement
- Structural response
- Numerical model verification and validation

Tools include MATLAB, OpenFAST and MoorDyn.

### 2. Floating Elastic Plate — Analytical and Neural Modelling

Developed analytical and neural network models to investigate
the dynamic response of floating elastic structures.

The research combines mathematical modelling, numerical
methods and machine learning.

**Research project:**

https://sboral1212.github.io/floating-plate-viscoelastic-foundation/

### 3. Python–MATLAB Research Simulation API

Developed a Python Flask-based interface that enables
researchers to access MATLAB numerical simulations
through a web browser.

Features include:

- Simulation job submission
- Input parameter management
- Job status tracking
- Automated MATLAB execution
- Results retrieval
- CSV and JSON outputs
- Graphical results
- Time-limited access tokens

**Research simulation interface:**

https://crock-dreadlock-trowel.ngrok-free.dev/

Note: The interface is a research prototype.
Access depends on the local service and ngrok tunnel
being active.

### 4. Quantum Algorithms for Differential Equations

Research on quantum numerical algorithms for solving
differential equations.

Current work includes:

- Kacewicz-based quantum algorithms
- Hybrid quantum–classical computational methods
- Quantum circuit formulations
- Numerical analysis of quantum algorithms
